# DF4robot · 数据怎样变成动作

**26页中文动态科普：从卡尔曼融合、四足运动，到 LIO、SCAN、VbotNav 与无人机导航。** 更新：2026-10-23。

演讲围绕四个问题：什么形状的数据、多久更新、途中变成什么、什么时候进入动作控制。公式配合动图、代入数字和符号解释；论文提供具体案例与可点击来源。

## 打开演示

下载仓库，双击 [deck/deck.html](deck/deck.html)，用Chrome或Edge打开。全部图形、CSS和JavaScript均已内联，断网可播放；GitHub代码页不直接运行HTML。

- `← →` / 空格：翻页；数字：跳页；`G`：目录；`F`：全屏。
- `P`：播放/暂停；`J / K`：下一步/上一步；`R`：重播当前页。
- 每页四步，自动播放一轮后停住。可以点击任意步骤，定格讲解。
- `N`：讲稿与来源。第3页拖动测量方差，观察卡尔曼权重与结果变化。
- 论文配图可点击放大，`Esc` 关闭；项目和论文链接位于页眉。图片已内联，离线也可查看。
- 系统设置减少动态效果时，默认暂停，可手动播放。

## 讲解路径

| 页 | 主题 | 观众看到的变化 |
|---|---|---|
| 1–2 | 总通路与传感器 | 6轴数据、距离图、XYZ点各自是什么 |
| 3–5 | 卡尔曼与异步 | 权重、误差范围、预测校正、不同频率更新 |
| 6–8 | 对齐与状态融合 | 像素→XYZ、点面误差→状态、定位与运控分工 |
| 9–13 | 四足爬高台 | 射线→局部格→419维输入→12关节动作；训练和控制时钟 |
| 14 | Extreme Parkour | 深度→CNN/GRU→视觉特征→关节命令，10/50Hz与延迟 |
| 15–17 | 从运动到导航 | 训练地图与导航接口；LIO 的预测、去畸变、几何校正 |
| 18–19 | SCAN-Planner | 点云/位姿/目标→局部地图→轨迹→速度；计算与地图内存 |
| 20–22 | VbotNav 与通信 | 云端语义与机载避障；算力分账；图像、点云和路点带宽 |
| 23–24 | 高飞团队无人机导航 | 点云方向距离、深度特征与飞控安全层；论文实机图 |
| 25–26 | Go2 部署与收束 | 机载实时闭环、速度门与云端目标；接口四问 |

教学配置、本地仿真、论文设置和资源估算分开标注。相机新帧率不等于策略频率；双传感器输入不代表已证明双传感器收益。机制图为原创示意，五张论文/项目原图保留署名与来源，未声称新实机验证。论文没有公开的芯片、RAM 或实测带宽明确标为未知，不作为部署最低配置。

## 修改和检查

```powershell
python build_deck.py
node deck/verify_render.cjs
python deck/make_contact.py
```

演示本身不需要安装依赖。构建仅需要Python标准库；渲染检查需要Node.js、Playwright与Chrome；拼接预览需要Pillow。Playwright不在默认位置时设置 `NODE_PATH`；Chrome不在默认位置时设置 `CHROME`。

内容源为 `beginner_deck.py` 与 `navigation_slides.py`，图形与公式动画为 `deck/beginner.js` 和 `deck/navigation.js`，样式为 `deck/beginner.css`；构建后只有一个 `deck.html`，可单独打开。配图及来源清单在 `deck/media/navigation/`，可用 `research/collect_navigation_media.py` 重新获取（需 requests 和网络）。`deck/validation.json` 记录26页、104个阶段的布局、动效和交互检查结果。
