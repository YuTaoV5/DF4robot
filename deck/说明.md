## 演示

双击 `deck.html`，使用 Chrome / Edge 打开；全部 CSS、JS、SVG 内联，离线可用。外链只用于点击查看论文。

- 方向键 / 空格翻页，G 展开目录，F 全屏，数字键跳页。
- 第 22 页 J / K 手动推进 ESKF；第 10 页拖动滑块改变观测噪声。
- 第 14 页点击事件查看异步更新。N 显示当前页讲稿及论文链接。
- `#22` 指定初始页；`?anim=4#22` 截取动画最后一步。

所有机制图为自绘示意；概率示例为可复算的一维教学模型，不是机器人性能测试。设备频率范围为配置示例。所有性能结论遵守原论文实验范围。详见 `../research/综述.md` 和 `../research/论文索引.md`。

## 渲染

生成：`python build_deck.py`（在仓库根目录执行）。

Windows PowerShell：

```powershell
$env:CHROME='C:/Program Files/Google/Chrome/Application/chrome.exe'
python deck/render_preview.py deck/deck.html 54 deck/rendered 1
```

逐页图保留在本地 `rendered/`，总览图为 `预览-全部页面.png`。审阅意见与落实位置见根目录 `审阅与修改.md`。

本次最终 QA 使用 `verify_render.cjs`（Playwright + 无界面 Chrome）统一 1920×1080 视口，运行全部页面边界与交互检查；`make_contact.py` 拼接总览。最终记录见 `validation.json`，54 页通过，脚本错误和边界溢出均为 0。人工检查了全部缩略图及修订重点页。
