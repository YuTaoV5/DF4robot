# 数据怎样变成动作 · 演示说明

本版为18页科普演讲，2026-10-19更新，替代此前70页主讲稿。详细页码施工图和数字口径见[科普版数据口径](../research/科普版数据口径.md)。

## 演讲方式

每页用四步回答一个问题。自动播放一轮约15秒后停止；P播放/暂停，J/K逐步，R重播，方向键翻页，G目录，数字跳页，F全屏，N讲稿。第3页滑块改变测量方差，同时重算修正比例、均值与误差方差。

公式紧跟图中正在发生的步骤：先看对象、理解问题，再解释符号与数字。例如卡尔曼展示预测0米、测量2米，代入K=P/(P+R)解释80%的修正比例；图像反投影解释像素、内参与距离如何得到XYZ；策略页解释419个输入数如何输出12个关节目标。论文来源可点击页眉查看。

## 重新生成与验收

```powershell
python build_deck.py
node deck/verify_render.cjs
python deck/make_contact.py
```

核对全部18页的72个阶段、SVG与舞台边界、卡尔曼数字及滑块响应、播放暂停、逐步、菜单、数字翻页和讲稿。另检查每页至少一个阶段有实际几何运动，避免只把静态图逐项点亮。

截图存放在本地`rendered/`，总览图`预览-全部页面.png`与机器记录`validation.json`随仓库发布。机器检查不能替代视觉审查，所有分组预览与重点动画阶段另行人工查看。
