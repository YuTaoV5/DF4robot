# 机器人多传感器融合：从概率估计到 VLA

检索截止：2026-10-13。配套 [54 页可视化讲解](../deck/deck.html)、[逐页讲稿](../deck/讲稿.md)、[53 项论文索引](论文索引.md)。本文是覆盖主要方法族的定向综述，不宣称穷尽所有论文，也没有在统一机器人平台上复测各系统。

## 1. 可以直接采用的结论

1. **频率不同是正常情况。** 用 IMU 在测量之间传播状态，其他观测按采集时刻更新；优化系统使用预积分或连续时间轨迹。强制插值到同一频率不是必要条件，也不会产生新信息。
2. **噪声不必同分布、同维度或同单位。** 先写出每类观测模型，再对残差和协方差做白化。需要高斯近似的是局部误差或条件残差，不是整张图像或整帧点云。
3. **默认工程路线是可解释的几何概率后端。** ESKF/迭代滤波适合受限资源、低延迟前端；滑窗/因子图适合回溯、标定和多约束管理。两者可组合。
4. **真正难点是时间、标定、关联、相关性和可观性。** 算法名字比这些基础问题更容易更换。更多传感器只有在带来有效互补约束时才有价值。
5. **学习优先补充可靠性和前端，再讨论完整替代。** 学特征、位移、偏置、噪声和模态门控均已有代表方法；必须检查跨场景、跨设备及不确定性校准。
6. **VLA 是动作策略层的重要进展。** 典型 OpenVLA/π0 并不提供可直接替代 IMU–Camera–Radar 里程计的完整标定、时间模型与状态协方差。移动操作通常更适合“估计 + 策略 + 反馈控制”的组合。

以上为综合工程判断，具体条件与来源见下文，不能解释为某篇论文证明了所有结论。

## 2. 问题定义与术语

本文同时讨论 LiDAR（激光测距）与毫米波 Radar（射频雷达）。4D 成像 Radar 通常提供距离、方位、俯仰和径向速度；旋转 Radar 可能主要提供极坐标强度扫描，并非所有设备都输出可直接使用的逐点 Doppler。

里程计估计局部相对运动，允许随距离累积漂移；SLAM 加上地图与可能的回环；全局定位还可能使用 GNSS、已知地图、UWB 或外部定位参考。报告指标时不能混同。

三组容易混淆的术语：

| 分类 | 选项 | 含义 |
|---|---|---|
| 信息层次 | 原始 / 特征 / 状态 / 决策 | 融合发生在处理链的哪一层 |
| 耦合程度 | 松 / 紧 / 混合 | 融合独立估计输出，还是共同状态下的观测残差 |
| 推断方式 | 滤波 / 平滑 / 学习 / 策略 | 怎样保留信息与求解，或者直接产生动作 |

“紧耦合”不意味着所有原始数据进入同一个矩阵；“特征融合”不必然是深度学习；“多模态”也不必然输出里程计。早/中/晚期融合在检测中的使用可见 [Vision-Radar BEV survey](https://arxiv.org/abs/2302.06643)。

## 3. 统一状态与测量模型

定义 W 为世界系、B 为 IMU 机体系；$R^W_B$ 将 B 中向量旋转到 W。基本状态

$$x=\{R^W_B,p^W_B,v^W_B,b_g,b_a\}.$$

名义姿态在 $SO(3)$ 上，局部误差为 $\delta\theta\in\mathbb R^3$。例如右扰动约定 $R=\hat R\operatorname{Exp}(\delta\theta)$；使用左扰动也可以，但雅可比、协方差和重置公式必须一致。可按任务增广重力、外参、时差、曝光、轮速比例和地图量。[ESKF 旋转基础](https://arxiv.org/abs/1711.02508)

对模态 s，在采集时刻 $t_s$ 定义

$$z_s=h_s(x(t_s),\theta_s)+n_s,\qquad r_s=z_s-h_s(\hat x(t_s),\hat\theta_s).$$

其中 $\theta_s$ 为标定等参数。融合对状态产生约束，而不是让一个像素与一个加速度数值直接相加。

| 模态 | 简化约束 | 需要处理的细节 |
|---|---|---|
| IMU | $\dot R=R[\omega_m-b_g]_{\times}$，$\dot v=R(a_m-b_a)+g$，$\dot p=v$ | 比力而非重力补偿后的直接加速度；偏置、轴系、饱和与温漂 |
| 视觉几何 | $r_c=z_c-\pi(T^C_Wp_f^W)$ | 深度、遮挡、误关联、滚动快门、镜头模型 |
| 视觉直接法 | 当前亮度与参考 patch 经几何变换后的差 | 曝光、响应函数、光照变化与非 Lambertian 表面 |
| LiDAR | $r_l=n^T(T^W_Lp_l-q)$ | 点时间、法向、对应面和地图不确定性 |
| Radar | $d_i=-u_i^Tv^R+\epsilon_i$（静态散射点） | 动态物体、角度噪声、多径与杆臂 |

Radar 中 $u_i$ 为视线单位向量，d 取距离增加为正；$v^R=R^R_B(R^B_Wv^W+\omega^B\times t^B_R)$。多个静态视线构成线性速度约束，视线矩阵不足秩时不能恢复完整三维速度。角度有误差时，投影误差依赖运动速度，不能只用一个固定 Doppler 方差。参考 [Multi-Radar](https://arxiv.org/abs/2311.08608) 和 [TRaIL-Odom 方法 III 节](https://arxiv.org/abs/2609.03561)。

## 4. 高斯为什么能融合，以及什么时候不成立

### 4.1 不同协方差并不矛盾

在小误差邻域，$\delta x\sim\mathcal N(0,P)$，各类残差可分别使用 $\Sigma_s$。协方差可以各向异性、时变、异方差且维数不同。令 $\Sigma_s=L_sL_s^T$，白化后 $\tilde r_s=L_s^{-1}r_s$ 是无量纲量。

MAP 的典型形式是

$$\min_X\|r_{prior}\|^2_{\Sigma_{prior}^{-1}}+\sum_s\rho_s(r_s^T\Sigma_s^{-1}r_s).$$

若高斯且独立、$\rho(s)=s$，这对应加权最小二乘；强相关时需联合协方差的非对角块。地图、标定参数是共同随机量时，条件独立假设需要明确。参考 [流形预积分](https://arxiv.org/abs/1512.02363) 与 [FAST-LIVO2 IV 节](https://arxiv.org/abs/2408.14035)。

### 4.2 可复算的小例子

仅考虑同一时刻的一维位置：先验 $\mu_0=0,\sigma_0=2$；两个独立、无偏的直接位置观测 $z_c=1,\sigma_c=1$ 与 $z_l=1.2,\sigma_l=0.5$。则

$$P^{-1}=0.25+1+4=5.25,$$
$$\mu=(0.25\times0+1\times1+4\times1.2)/5.25=1.104762,$$
$$P=0.190476,\quad\sigma=0.436436.$$

第 10 页按这些公式实时重算。这个例子没有声称 IMU 本身输出无偏位置，也没有把真实图像当作位置测量。

### 4.3 原始数据与残差经常不高斯

- IMU 常用白噪声 + 偏置随机游走，但温漂和振动可带来有色噪声；需要静态和动态数据验证。
- 视觉错误匹配、LiDAR 错误平面、Radar 动态点与多径造成重尾和混合分布。
- Huber/Cauchy 等鲁棒损失、创新门控、RANSAC 或 GNC 可减少离群点影响，但不能保证所有数据关联都正确。
- Student-t 可描述厚尾；Gaussian mixture 或粒子方法可保留多峰；复杂度和分量管理是代价。UKF 通常仍是均值协方差近似，不自动解决多峰。

文献入口：[Student-t 多传感器滤波](https://arxiv.org/abs/2204.11098)、[Gaussian mixture fusion](https://arxiv.org/abs/2506.00383)、[iRIOM 的鲁棒 Radar 处理](https://arxiv.org/abs/2303.13962)。前两篇并不等于在本任务四模态机器人上的完整验证。

### 4.4 相关性与重复计数

若 VIO 和 LIO 共用 IMU、先验或地图，它们的位姿误差相关。把两个高斯输出当独立证据相乘，容易低估不确定性。可选：联合状态与因子；维护交叉协方差；或在一致输入假设下使用 Covariance Intersection 等保守融合。

$$P_{CI}^{-1}=\omega P_1^{-1}+(1-\omega)P_2^{-1},\quad0\leq\omega\leq1,$$
$$\hat x_{CI}=P_{CI}[\omega P_1^{-1}\hat x_1+(1-\omega)P_2^{-1}\hat x_2].$$

这里是共同欧氏坐标中的公式；位姿必须先定义一致局部误差。CI 权重并非真实独立精度相加；它强调未知相关性下的保守性，可能牺牲信息。[含 CI 讨论的 Student-t 融合论文](https://arxiv.org/abs/2204.11098)。

## 5. 多频率、不同延迟与时空标定

### 5.1 三个时钟要分清

采集时间决定物理约束；到达时间决定系统调度；状态发布时间决定控制可用性。应记录两种原始时间及各模块延迟。

示例配置是 IMU 200 Hz、Camera 20 Hz、Radar 20 Hz 且偏移 25 ms、LiDAR 10 Hz。算法按采集时间维护事件队列。不同频率不是同步故障，未知时钟偏移才是需要估计或校正的问题。

```text
on_message(m):
    保留采集时刻、到达时刻、坐标系、序列号、质量字段
    检查时钟域和标定参数，将消息加入有界队列
    if m 是 IMU:
        缓存数据；传播可连续发布的状态与协方差
    else:
        t = 已校正的采集时刻
        if t 仍在缓存或平滑窗口中:
            在 t 建立观测；进行门控和更新/优化
            必要时重传播到当前时刻
        else:
            按明确策略丢弃、记录，或仅交给离线/全局后端
    输出状态、协方差、观测年龄、质量模式
```

### 5.2 传播噪声必须随 dt 变化

$$P_{k+1}=\Phi P_k\Phi^T+Q_d,\qquad Q_d=\int_0^{\Delta t}\Phi(\tau)GQ_cG^T\Phi(\tau)^T d\tau.$$

对一维白加速度噪声驱动的 $[p,v]$，$Q_d=q\begin{bmatrix}\Delta t^3/3&\Delta t^2/2\\\Delta t^2/2&\Delta t\end{bmatrix}$。对偏置随机游走，增量方差为 $q_b\Delta t$。连续噪声密度不能直接当每样本标准差；理想区间平均白噪声的方差随 $1/\Delta t$ 缩放，实际还取决于采样滤波/带宽定义。[ESKF](https://arxiv.org/abs/1711.02508)

### 5.3 预积分、去畸变与连续时间各解决什么

| 技术 | 作用 | 不应误解为 |
|---|---|---|
| IMU 预积分 | 用 $\Delta R,\Delta v,\Delta p,\Sigma,J_b$ 表示关键帧间运动 | 把 IMU 平均成相机频率 |
| LiDAR 去畸变 | 将逐点采样映射到共同参考时刻 | 一帧内所有点天然同步 |
| 连续时间轨迹 | 在任意采样时刻计算位姿及导数 | 无限运动带宽或零系统延迟 |
| 固定滞后平滑 | 修正窗口内的历史状态 | 任意晚到测量都可免费接入 |

预积分会在偏置变化较大时需要重积分；连续时间样条的节点间距是计算与带宽的取舍。[预积分](https://arxiv.org/abs/1512.02363)、[连续/离散时间比较](https://arxiv.org/abs/2202.08894)。

### 5.4 校准不能被融合自动替代

外参、时间偏移、内参以及 IMU 噪声都应建立可复现的标定流程。多轴旋转与平移激励提高参数可辨识性；平面匀速运动可能让参数高度相关。在线估计是补充，不是缺少激励时的万能恢复。

局部一阶估计：$\Delta p\approx v\Delta t$，5 m/s 与 20 ms 对应 10 cm；$\Delta\theta\approx\omega\Delta t$，1 rad/s 与 20 ms 对应约 1.15°。这是量级推导，不是实测性能。

入口：[在线时间标定](https://arxiv.org/abs/1808.00692)、[iKalibr](https://arxiv.org/abs/2407.11420)、[RIs-Calib](https://arxiv.org/abs/2408.02444)。

## 6. 传统推断方案的完整方法地图

| 方法族 | 核心 | 主要收益 | 限制 |
|---|---|---|---|
| KF | 线性高斯递推 | 在假设下精确 | 真实姿态/投影非线性 |
| EKF | 一阶线性化 | 高效、易组合观测 | 初始化、线性化和一致性 |
| ESKF | 名义状态与局部误差分离 | 自然处理惯性与姿态 | 需要重置和约定一致 |
| Iterated ESKF | 同一先验下迭代线性化 | 改善局部测量拟合 | 不是增加独立信息 |
| InEKF | 利用群结构与不变误差 | 合适系统下误差性质更好 | 条件性理论，不是普适全局保证 |
| UKF | sigma-point 矩传播 | 减少手推雅可比需求 | 高维代价、单峰近似 |
| MSCKF | 克隆位姿 + 特征零空间消元 | 避免长期维护全部特征 | 关联、激励和一致性 |
| 滑窗 MAP / FGO | 多时刻状态与稀疏因子 | 可重线性化、易加入约束 | 边缘化先验固定与窗口代价 |
| 增量平滑 | 局部更新稀疏解 | 减少全批量重算 | 取决于图结构 |
| 连续时间优化 | 轨迹函数 + 任意时刻残差 | 逐点异步建模 | 参数化带宽与初始化 |
| 鲁棒/混合/粒子 | 非高斯或多假设推断 | 重尾、多峰表达 | 更高计算与调参成本 |
| 分布式/CI | 处理未知相关性和多个估计 | 模块化与保守一致性 | 可能丢失信息 |

### 6.1 ESKF 更新流程

$$r=z-h(\hat x^-),\quad S=HP^-H^T+\Sigma,$$
$$K=P^-H^TS^{-1},\quad\delta x=Kr,\quad\hat x^+=\hat x^-\boxplus\delta x.$$

通过线性求解实现增益，避免显式大矩阵求逆。使用数值稳定的协方差更新，例如 Joseph 形式；随后应用误差重置雅可比。门控 NIS 为 $r^TS^{-1}r$。迭代滤波必须始终保留原先验，避免反复将同一测量作为新证据。[ESKF](https://arxiv.org/abs/1711.02508)

### 6.2 MSCKF 与因子图

MSCKF 的线性残差 $r\approx H_x\delta x+H_f\delta f+n$，用满足 $N^TH_f=0$ 的左零空间消去特征误差。克隆状态间相关性仍保留。[MSCKF 作者报告](https://intra.ece.ucr.edu/~mourikis/tech_reports/TR_MSCKF.pdf)、[OpenVINS](https://docs.openvins.com/)

图优化把 IMU、视觉、几何、Doppler、回环、GNSS 等作为因子。边缘化通过 Schur 补把旧状态压入先验；线性化点冻结可能影响一致性。iSAM2 使用 Bayes tree 增量更新，而非每次全图从零求解。[iSAM2 作者论文](https://people.csail.mit.edu/kaess/pub/Kaess12ijrr.pdf)

### 6.3 可观性与退化

一般无全局参考的 VIO 中，全局平移和重力方向轴上的全局航向不可观。单目视觉本身尺度不定；惯性尺度恢复依赖激励。平面、长廊、纯旋转、近共线 Radar 视线产生不同的局部弱方向。

局部信息矩阵 $\Lambda=H^T\Sigma^{-1}H$ 的谱可用于诊断，但必须说明变量单位、归一化、先验与选择的子块。某个阈值下的小特征值并不是严格非线性可观性证明。把方向特征值全部放大也不会创造新观测。[InEKF](https://arxiv.org/abs/1410.1465)、[接触辅助 InEKF](https://arxiv.org/abs/1805.10410)

## 7. 里程计系统的选型证据

### 7.1 VIO 与 LIO

OpenVINS 适合研究滤波基本机制和一致性；VINS-Mono 是滑窗 VIO 的重要基线；ORB-SLAM3 把视觉惯性与多地图和重定位连接起来。FAST-LIO2 强调迭代滤波、原始点配准和增量地图；LIO-SAM 以因子图接入惯性和全局约束。[VINS](https://arxiv.org/abs/1708.03852)、[ORB-SLAM3](https://arxiv.org/abs/2007.11898)、[FAST-LIO2](https://arxiv.org/abs/2107.06829)、[LIO-SAM](https://arxiv.org/abs/2007.00258)

### 7.2 LIVO 不是只有一种组织方式

LIC-Fusion 2.0：平面跟踪、滤波与在线时空标定。LVI-SAM：视觉惯性与激光惯性子系统互助。R3LIVE：几何与颜色地图支持的两类估计。FAST-LIVO2：统一体素地图和序贯滤波。[LIC-Fusion 2.0](https://arxiv.org/abs/2008.07196)、[LVI-SAM](https://arxiv.org/abs/2104.10831)、[R3LIVE](https://arxiv.org/abs/2109.07982)

FAST-LIVO2 原文 IV 节有重要边界：**外参与时间偏移已知；LiDAR 点按图像采样时刻重组；先 LiDAR 更新，再视觉更新。** 其概率分解基于给定状态的观测独立性；实际非线性迭代、地图近似和重线性化不保证任意顺序实现结果完全相同。[FAST-LIVO2](https://arxiv.org/abs/2408.14035)

### 7.3 Radar 的主要路线

1. Doppler 自速度 + IMU：可无扫描匹配工作，计算结构简洁，但方向退化与长期漂移仍在。
2. Doppler + 扫描子图：iRIOM 用鲁棒自速度、几何配准和迭代滤波，另有回环。
3. 物理增强关联：利用 Doppler/RCS 过滤动态点、改进对应。
4. 直接强度法：DRO 面向旋转 Radar 的 SE(2) 直接配准，并处理扫描运动和 Doppler 畸变；其特殊多普勒约束需硬件波形支持。
5. 学习式 Radar-only 或多模态：Radarize、Raci-Net 等，分别作为传感器简化或恶劣天气的路线，不能混同其输入模态。

入口：[Multi-Radar](https://arxiv.org/abs/2311.08608)、[DeRO](https://arxiv.org/abs/2403.05136)、[iRIOM](https://arxiv.org/abs/2303.13962)、[Physical-enhanced RIO](https://arxiv.org/abs/2402.02200)、[DRO](https://arxiv.org/abs/2504.20339)、[扫描匹配是否必要](https://arxiv.org/abs/2310.18117)、[Radarize](https://arxiv.org/abs/2311.11260)、[Raci-Net](https://arxiv.org/abs/2507.10376)。

### 7.4 截至 2026 年的方向

- **TRaIL-Odom**：连续时间 Radar–IMU–LiDAR；按 LiDAR 平移弱方向调整逐点 Doppler 权重，并做扫描级增益调节。方法正文明确名义残差权重是经验缩放系数，不能解读为经过统计标定的真实精度。原摘要报告三条退化序列消融中，相对固定权重基线 RMSE ATE / RTE 降低 86.0% / 78.5%；这不是通用性能保证。[原文](https://arxiv.org/abs/2609.03561)
- **SA-LIVO**：联合 LiDAR–视觉信息矩阵的特征方向门控，弱方向抑制与强方向保留。和 TRaIL 主动加强弱方向的做法不同。[原文 v2](https://arxiv.org/abs/2606.25699)
- **FIRE-LIVWO**：矿井中的 LiDAR、IMU、视觉、轮速和 Radar 退化管理。额外的轮式运动约束和应用环境必须计入比较条件。“Failure-Immune”是方法命名，不是零故障证明。[原文](https://arxiv.org/abs/2609.05325)
- **LBDU-VIO**：MSCKF 内学习连续偏置动力学和 IMU 不确定性。原始摘要给出 EuRoC 10 s 视觉中断条件下，相对 S-MSCKF 的平均相对位置误差改善；其跨设备稳定性需独立复现。[预印本](https://arxiv.org/abs/2609.39125)

前两条中 TRaIL arXiv 评论注明 RA-L 接收，FIRE 注明 IROS 2026 接收；这是作者在页面中的信息。没有把 SA-LIVO、LBDU 和 TacVLA 擅自标成已正式发表。

## 8. 学习式融合、VLA 与机器人应用

### 8.1 以物理后端为接口的学习路线

可学习特征与匹配、模态门控、位移及协方差、偏置和过程噪声，也可端到端预测位姿。TLIO 将网络预测的三维相对位移与不确定性送入克隆 EKF，训练域为头戴式行人运动；DROID-SLAM 将学习迭代与稠密几何优化结合，原始工作是视觉 SLAM；Selective VIO 学习视觉惯性特征选择。[TLIO](https://arxiv.org/abs/2007.01867)、[DROID](https://arxiv.org/abs/2108.10869)、[Selective](https://arxiv.org/abs/1903.01534)

若学习协方差，使用正定参数化，如 $\Sigma=LL^T+\epsilon I$。高斯 NLL 有 $r^T\Sigma^{-1}r+\log\det\Sigma$ 两项；只保留第一项可能鼓励任意放大方差。必须在分布外数据检查覆盖率、NIS/NEES；attention 权重不等于经过校准的概率可靠度。

### 8.2 VLA 的贡献与边界

RT-2 将动作编码进视觉语言学习；OpenVLA 提供开源 VLA 路线；Octo 通过模块化观测和动作接口适配机器人；π0 用 flow matching 产生连续动作块；π0.5 强化异构数据和语义子任务的共训练。[RT-2](https://arxiv.org/abs/2307.15818)、[OpenVLA](https://arxiv.org/abs/2406.09246)、[Octo](https://arxiv.org/abs/2405.12213)、[π0](https://arxiv.org/abs/2410.24164)、[π0.5](https://arxiv.org/abs/2504.16054)

这些融合通常发生在 token/特征/策略层。不会自动给出状态协方差、正确 Radar 似然、逐点时间、空间标定或里程计可观性。动作分布也不同于状态估计误差分布。Diffusion Policy 是动作扩散的重要前身，基础模型并非必须包含语言；flow matching 与 diffusion 的训练目标应分开说明。[Diffusion Policy](https://arxiv.org/abs/2303.04137)

Tactile-VLA 连接触觉反馈与位置力控制；TacVLA 在接触检测后激活触觉 token。它们展示任务阶段与模态选择的价值，但没有证明四模态里程计可被统一 VLA 全面替代。[Tactile-VLA](https://arxiv.org/abs/2507.09160)、[TacVLA v4](https://arxiv.org/abs/2603.12665)

### 8.3 扩展到机器人任务

| 应用 | 融合对象 | 应保留的物理/统计接口 |
|---|---|---|
| 飞行定位 | 视觉、IMU、测距/事件 | 低延迟姿态与速度、观测年龄 |
| AMR/矿井导航 | LiDAR、Radar、IMU、轮速 | 地面运动假设、滑移、几何退化 |
| 腿式机器人 | IMU、接触、关节编码器、视觉 | 接触概率、滑移与切换 |
| BEV 感知 | 相机、LiDAR、Radar | 坐标投影、检测置信度、跟踪状态 |
| 移动操作 | 里程计、地图、图像、语言 | 地图/本体坐标一致、状态质量 |
| 接触操作 | 视觉、语言、力、触觉 | 力反馈、动作时效、接触状态 |
| 多机器人 | 相对观测、地图、局部估计 | 共有先验和通信延迟、相关性 |

接触估计代表 [Contact-aided InEKF](https://arxiv.org/abs/1805.10410)；事件扩展见 [事件融合综述](https://arxiv.org/abs/2410.15480)。对声呐、DVL、GNSS、UWB 等可使用同一状态/因子原则，但本次不把它们扩展为独立全面综述。

## 9. 产品路线、成本和验收

### 9.1 场景驱动选型

轻量飞行/XR 优先 VIO；普通巡检先建立 LIO；需要纹理与几何互补再增加视觉；恶劣能见度或几何退化再评估 Radar；接触任务增加触觉/力；多任务语义操作再引入 VLA。全传感器方案会增加同步硬件、标定工装、算力、线束、功耗、数据存储和维护成本，不能仅按传感器单价决策。

### 9.2 可执行验收清单

| 维度 | 必须固定或报告 |
|---|---|
| 数据 | 时间戳定义、硬件、标定、所有序列、真值有效区间 |
| 精度 | ATE/RPE、旋转/平移、时间/距离间隔、SE(3)/Sim(3) 对齐 |
| 鲁棒性 | 失败数、失败定义、最坏序列、恢复时间、降级模式 |
| 统计一致性 | NIS、NEES（有真值）、覆盖率、可观子空间/gauge 处理 |
| 实时性 | 采集到输出 P50/P95/P99、丢帧、队列年龄、动作缓冲年龄 |
| 资源 | 相同硬件下 CPU/GPU、峰值内存、稳态功耗与热降频 |
| 策略 | 闭环成功、接触失误、恢复与新场景表现 |

任务需要的阈值由平台和速度预算导出，而不是从任意论文摘一个数字。例如允许状态滞后造成的位置误差预算为 $e_t$，在最大速度 $v_{max}$ 下，一阶要求观测/状态年龄不超过 $e_t/v_{max}$；旋转也要用角速度与允许角误差约束。这只是时效误差预算，不是总定位误差保证。

### 9.3 最小实验矩阵

冻结硬件/标定/回环配置后，对 IMU+V、IMU+L、IMU+R 和联合系统比较；加入遮挡、曝光变化、长廊、动态目标、时间偏移、随机延迟、乱序和丢帧。固定与自适应噪声、方向权重分别消融；学习方法按场景/设备划分训练测试；VLA 采用一致任务、示教量和执行预算。

数据入口：[Boreas](https://arxiv.org/abs/2203.10168)、[NTU4DRadLM](https://arxiv.org/abs/2309.00962)、[Boreas Road Trip](https://arxiv.org/abs/2602.16870)。EuRoC/TUM-VI 支持 VIO；LIVO 方法附带数据适合复现各自配置。任何一个数据集都不能支持全部模态与部署结论。

## 10. 最值得继续研究的缺口

1. 方向相关的自适应权重如何获得可校准概率解释，而非仅经验调节？
2. 时间偏移、动态关联和噪声变化能否被正确区分，避免滤波器以膨胀协方差掩盖标定错误？
3. 学习的偏置/噪声模型如何跨设备迁移，失效时如何回到保守物理基线？
4. VLA 如何消费带时效与不确定性的状态，而不是把过期状态当最新观测？
5. 如何同时评价感知估计误差、策略任务成功和失效后的恢复？

建议的研究优先级是“可观性与时间正确性 → 鲁棒不确定性 → 跨域学习 → 任务级融合”。每一项都应通过消融与闭环评价，而不是仅增加模型复杂度。
